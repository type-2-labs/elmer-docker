# elmer-docker

[Elmer FEM](https://www.csc.fi/web/elmer) 9.0 from CSC's official Ubuntu PPA, with gmsh, headless.
CPU (MPI) solver: thermal with radiation view factors, structures, electromagnetics and more.

Image: `ghcr.io/type-2-labs/elmer:9.0` (built by GitHub Actions on every push to `main`).

- `ElmerSolver`, `ElmerGrid`, `ViewFactors`, `gmsh`, `mpirun` on `PATH`
